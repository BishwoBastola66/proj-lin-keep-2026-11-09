## 1. Abstract & Navigation

This document establishes the authoritative mapping connecting abstract academic theories to concrete source code implementations across the unified Rubix compiler repository. 

Every principle, optimization pass, and security invariant is explicitly mapped to:
1. **Source Code Location** in `compiler/`, `std/`, `tests/`, or `examples/`.
2. **Intermediate Representation** (`SIR`, `AIR`, `UIR`, `RUMS`).
3. **Automated Verification Test**.
4. **Empirical Measurement & Status**.
