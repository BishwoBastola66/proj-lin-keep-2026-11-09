# Computing and Optimization History: The 1950s & The Origin of Compiler Optimization

## 1. Hardware Architecture & Physical Constraints
* **Representative Systems**: IBM 701 (1952, Williams tubes), IBM 704 (1954, first commercial machine with magnetic core memory and hardware floating point), UNIVAC I (1951), Ferranti Mark 1.
* **Core Technological Shifts**:
  * **Magnetic Core Memory**: Invented by An Wang and Jay Forrester; provided true non-volatile, random-access memory (access time ~12 µs), eliminating rotational delay line bottlenecks.
  * **Hardware Floating-Point (IBM 704)**: Provided dedicated 36-bit floating-point registers and instructions (`FAD`, `FSB`, `FMP`, `FDV`), radically accelerating scientific computing.
  * **Hardware Index Registers**: The IBM 704 had three 15-bit index registers (Registers A, B, C; accessed via 2's complement subtraction). This eliminated the need to use self-modifying code for loops and array subscripting.

---

## 2. What Was Expensive?
* **Computer Rental Time**: An IBM 704 rented for approximately \$30,000 to \$50,000 per month (in 1955 dollars, equivalent to over \$400,000/month today). Machine time cost roughly \$300 to \$600 per CPU hour.
* **Core Memory Size**: The IBM 704 initially shipped with 4,096 36-bit words (expandable to 8,192 and later 32,768 words).
* **Human Programmer Salaries vs. Machine Time**: Management regarded programmers as cheap compared to the staggering cost of computer cycles. If a high-level language program ran even 10–20% slower than hand-coded assembly, customers would refuse to use the compiler because the extra machine hours would exceed human programmer savings.

---

## 3. What Was Slow?
* **Magnetic Tape I/O**: Compilers ran in multiple distinct passes, storing intermediate representations (IR) on magnetic tapes that spun back and forth.
* **Floating-Point Multiplication & Division**: Although orders of magnitude faster than software emulation, FP multiplication still took ~200 µs on the 704.

---

## 4. What Programmers Optimized Manually
* **Register Allocation of the 3 Index Registers**: Juggling indices across inner nested loops without spilling to core memory.
* **Common Subexpression Elimination (CSE)**: Hand-factoring complex algebraic equations to minimize arithmetic instructions.
* **Loop Induction Variable Simplification**: Computing array addresses by incrementing pointers directly rather than performing full offset multiplication (`i * stride`) on every iteration.

---

## 5. What Compilers Optimized Automatically (The FORTRAN I Breakthrough)
In 1954–1957, John Backus led a small team at IBM (including Lois Haibt, David Sayre, Peter Sheridan, Robert Nelson, Harlan Herrick, and Richard Goldberg) to create the first FORTRAN compiler for the IBM 704.
Backus understood that FORTRAN would fail unless it generated machine code as efficient as that produced by master human assembly coders.

The FORTRAN I compiler introduced the world's first automated optimization techniques:
1. **Section 4 & Section 5 (The Optimizer)**:
   * **Common Subexpression Elimination (CSE)**: Sheridan and Backus devised algorithms to identify syntactically identical subexpressions within basic statements and reuse evaluation results in registers.
   * **Strength Reduction**: Multiplying an index by array element stride (`A(I)`) inside a loop was transformed into repeated addition of the stride to an index register.
   * **Loop Frequency Analysis & Branch Probability (Monte Carlo simulation)**: Lois Haibt pioneered control flow graph analysis. Because execution profiles were unknown, Haibt's pass used a simulated flow method: it evaluated branch conditions, estimated loop execution counts, and predicted which paths were "hot" vs. "cold".
   * **Optimal Index Register Allocation**: With only 3 index registers on the IBM 704, Section 5 formulated register allocation as a graph optimization problem over basic blocks, determining optimal spill and restore locations based on Haibt’s frequency estimates.

---

## 6. Hardware Limitations Imposed on Software
* **Fixed Register Files**: Exactly 3 index registers (decremented by hardware) and 1 accumulator (`AC`) + 1 multiplier-quotient (`MQ`) register.
* **Drum/Tape Memory Swapping**: The compiler itself could not fit into the 4K core memory at once. It had to be split into 6 strict sequential phases, passing intermediate tables via magnetic tape.

---

## 7. Breakthrough That Changed Compiler Design
* **The FORTRAN Project (1957)**: Proved that high-level languages were not just theoretical toys for academic paper design, but could generate production-grade machine code that matched human assembly in performance, reducing programming time by up to 80%.

---

## 8. Breakthrough That Changed Runtime Design
* **Standard Calling Conventions & Return Links**: Establishing fixed registers for function call linkages, argument passing, and stack frame precursors (Fortran used static allocation; recursive calls were forbidden, allowing static memory allocation for all variables).

---

## 9. Ideas That Survived
* Loop induction variable strength reduction.
* Common subexpression elimination (CSE).
* Graph-based control flow representation (precursor to CFG).
* Hot-path frequency estimation for register spilling.

---

## 10. Ideas That Disappeared
* **Static Memory Allocation for All Subroutines**: Fortran allocated all local variables at fixed, permanent memory addresses. This was eliminated by Algol 60's dynamic activation records on a call stack to allow recursion.
* **Three-way Arithmetic IF**: `IF (A - B) 10, 20, 30` directly mapped to IBM 704 conditional jump instructions (`TMI`, `TZE`, `TPL`), which disappeared from modern high-level languages.

---

## 11. Ideas That Returned Decades Later Under a Different Name
* **Lois Haibt's Branch Frequency Analysis**: Returned in the 1990s and 2000s as **Profile-Guided Optimization (PGO)** and static branch weight heuristics (e.g., Ball-Larus heuristics in modern LLVM/GCC).
* **Static Graph Register Allocation**: Returned in 1981 when Gregory Chaitin generalized register allocation using graph vertex coloring.
