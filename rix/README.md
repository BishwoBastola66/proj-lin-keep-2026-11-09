# Rix — The Official Package Manager & Executor for Rubix

**Rix** is the dedicated package manager and package executor for the **Rubix** systems programming language.

---

## 1. Architectural Role

```text
       RUBIX ECOSYSTEM
              │
     ┌────────┴────────┐
     │                 │
   Rubix              Rix
     │                 │
Core Language       Package
Compiler & RT       Manager & Runner
```

* **Rubix**: The core programming language, lexer, parser, typechecker, and native code generator.
* **Rix**: Package discovery, manifest handling (`Rix.toml`), dependency resolution, lockfiles (`Rix.lock`), package caching, integrity checks, and tool execution (`rix run`, `rix exec`).

## 2. Project Directory Structure


## 3. CLI Command Reference

### Package Management

```bash
# Initialize a new package with Rix.toml, src/main.bix, and Rix.lock
rix init [name]

# Initialize in a new directory
rix new <project_name>

# Add a dependency to Rix.toml and update Rix.lock
rix add <package> [version]

# Remove a dependency from Rix.toml and Rix.lock
rix remove <package>

# Resolve and install all dependencies declared in Rix.toml
rix install

# Recalculate lockfile hashes and update installed packages
rix update

# List declared dependencies and installed packages
rix list

# Display a dependency tree graph
rix tree
```

### Script & Tool Execution

```bash
# Execute a project script declared under [scripts] in Rix.toml
rix run <script> [args...]

# Run dev mode (default: runs main entrypoint or [scripts].dev)
rix dev

# Build standalone native executable
rix build

# Execute a package binary directly from local packages or workspace tools
rix exec <tool> [args...]
```

## 4. Manifest (`Rix.toml`) & Lockfile (`Rix.lock`) Specification

### `Rix.toml` Example:
```toml
[package]
name = "my_app"
version = "0.1.0"
edition = "2026"
entry = "src/main.bix"

[dependencies]
logger = "0.2.0"

[scripts]
start = "rubix run src/main.bix"
test = "rubix test"
build = "rubix build src/main.bix"
```

### `Rix.lock` Example:
```toml
# Rix Lockfile — Auto-generated by Rix Package Manager. DO NOT EDIT DIRECTLY.
version = 1

[root]
name = "my_app"
version = "0.1.0"
hash = "rix-56971"

[packages]
logger = { version = "0.2.0", hash = "rix-57256", source = "local" }
```

## 5. Verification

To run Rix internal test suites:

```bash
# Run Rubix unit tests
cat rix/src/manifest.bix rix/src/lockfile.bix rix/src/resolver.bix rix/tests/test_master.bix > rix/tests/t_unit.bix && ./rubix/bin/rubix run rix/tests/t_unit.bix && rm -f rix/tests/t_unit.bix

# Run End-to-End CLI workflow test
./rix/tests/test_cli_workflow.sh
```
