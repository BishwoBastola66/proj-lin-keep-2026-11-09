## 1. Executive Summary

This specification establishes the strict boundary demarcation between shared mechanisms and strictly independent components within the **Sovereign Autonomic Execution Substrate (SAES)**.

A critical design requirement of Rubix is to avoid the **Harmful Coupling Trap**: merging two distinct systems into a tangled monolith weakens both. This document proves why EIA-Omega and HNS-Hyperflux must share specific runtime primitives while preserving complete modular independence.

### 3.1 Why HNS Must Remain Independent of EIA
* **Standalone Compiler Utility**: HNS must be capable of emitting traditional, standalone, direct-syscall native binaries (`DDZRE`) that contain **zero EIA metadata** for ultra-constrained bare-metal microcontrollers where every byte counts.
* **No Runtime Overhead**: A binary compiled by HNS for a closed, static embedded device does not need runtime hole patching or Hologram parsing.

### 3.2 Why EIA Must Remain Independent of HNS
* **Polyglot Compiler Agnosticism**: EIA's Universal Hologram ($\Sigma_\infty$) is designed to outlive any individual programming language or compiler implementation.
* **Third-Party Compiler Support**: EIA must support binaries generated by GCC, Clang, Rustc, or future neural compilers. If EIA were hardcoded to HNS stencil internal structures, third-party compilers could not participate in the post-ABI continuum.

## 4. Boundary Enforcement Invariants

1. **`BOUND-INV-01` (Zero Compiler Leaks into Holograms)**: An `EIA_SymbolContract_v2` must never reference HNS-specific register allocation tokens, stencil opcodes, or compiler pass flags.
2. **`BOUND-INV-02` (Zero Loader Leaks into Stencils)**: A `PCMSS` machine stencil must consist purely of raw target ISA instructions; it must contain no references to operating system file headers, dynamic loaders, or external symbol tables.
3. **`BOUND-INV-03` (Clean Fallback)**: If an EIA binary is executed in an environment without the HNS daemon, the embedded `ARLL-Agent` resolves all relocations independently without spawning a compiler.
